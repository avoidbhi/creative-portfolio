36 days. 3D. Letterforms.

I wanted to learn 3D. I decided to start the 36 Days of Type challenge, and it turned into a study in letterforms.

One type design a day, for 36 days — each built from scratch in 3D, modelled, lit, rendered, and set in motion. The result is a reel of thirty-six animated type studies: the same discipline every day, a different letterform each time.

The point was never the software. The point was the repetition — a month of sitting with a single form until it stopped being a shape and started being a character.
